# OpenWrt x86_64 Build

[简体中文](README.md) | [正體中文](README.zh-TW.md) | [English](README.en.md) | **Русский**

[![Latest Release](https://img.shields.io/github/v/release/cashlau/OpenWrt-Build?label=Latest%20Release&style=flat-square)](https://github.com/cashlau/OpenWrt-Build/releases/latest)
[![OpenWrt](https://img.shields.io/badge/OpenWrt-Official-00B5E2?logo=openwrt&logoColor=white&style=flat-square)](https://openwrt.org/)

Автоматическая сборка прошивки **OpenWrt x86_64** на основе официального исходного кода OpenWrt с помощью GitHub Actions. В прошивку интегрированы популярные пакеты и дополнительные функции, готовые сборки публикуются в GitHub Releases.

Вы можете скачать готовую прошивку или **сделать Fork этого репозитория**, изменить пакеты, настройки и параметры сборки в соответствии со своим оборудованием и требованиями, а затем самостоятельно собрать прошивку с помощью GitHub Actions.

---

> **Совет:** Если вам нужна помощь с функциями, настройками или процессом сборки, вы можете передать **ссылку на этот репозиторий** таким AI-инструментам, как **ChatGPT, Claude или Gemini**, для анализа и помощи с конфигурацией.

## Основные возможности

- Автоматическое получение последней стабильной версии исходного кода OpenWrt и сборка с помощью GitHub Actions
- По умолчанию поддерживаются **简体中文、正體中文、English、Русский**
- По умолчанию используется **PPPoE**; на устройствах с несколькими сетевыми портами **eth1** назначается как WAN, а остальные физические Ethernet-интерфейсы используются как LAN; если эти условия не выполняются, сохраняется стандартная сетевая конфигурация OpenWrt
- Поддержка сетевых адаптеров **Intel X710 10GbE**
- Отображение температуры CPU, NVMe, чипсета и некоторых беспроводных адаптеров
- По умолчанию используется **тема Argon LuCI**, обеспечивающая более современный веб-интерфейс управления
- Автоматическая проверка и сборка последней стабильной версии каждую среду (UTC)
- Возможность сделать Fork, изменить пакеты и параметры сборки

## Предустановленные пакеты

- **PassWall**: прозрачный прокси, маршрутизация трафика по правилам и серверные функции; поддерживает удалённое подключение к домашней сети и выход в Интернет через прокси-шлюз домашнего маршрутизатора
- **MosDNS**: маршрутизация и оптимизация DNS, а также фильтрация рекламных доменов
- **PushBot**: уведомления через WeChat, DingTalk, Telegram и другие сервисы
- **Wake on LAN**: поддержка Etherwake и Wake-on-LAN
- **Dynamic DNS**: автоматическое обновление DNS-записей при изменении публичного IP-адреса
- **Nikki**: менеджер прозрачного прокси на базе Mihomo
- **Momo**: менеджер прозрачного прокси на базе sing-box
- **rtp2httpd**: преобразование IPTV-потоков RTP / UDP в HTTP
- **USB Print Server**: общий доступ к USB-принтеру по локальной сети
- **Cloudflare Tunnel**: доступ к внутренним сервисам без прямого открытия портов в Интернет

Настройки пакетов и источников программного обеспечения находятся в `scripts/ext_packages.sh` и `feeds.conf.default`.

## Использование

Скачать прошивку: https://github.com/cashlau/OpenWrt-Build/releases

Откройте в браузере: `http://192.168.50.1`

- Имя пользователя по умолчанию: `root`
- Пароль по умолчанию: пустой
- После первого входа рекомендуется сразу установить пароль

## Самостоятельная сборка

Сделайте Fork этого репозитория → измените конфигурацию → откройте **Actions** → нажмите **Run workflow** → дождитесь завершения сборки.

После завершения прошивку можно скачать из **Releases** или **Actions**. Локальная среда сборки OpenWrt не требуется.

## Примечания

- Прошивка собирается и тестируется только для платформы **x86_64**
- При первой установке или обновлении между основными версиями рекомендуется не сохранять старую конфигурацию
- По умолчанию используется PPPoE; имя пользователя и пароль вашего интернет-провайдера необходимо указать самостоятельно
- Протестированы некоторые сетевые адаптеры Intel X710; совместимость с другим оборудованием необходимо проверять самостоятельно
- Перед обновлением рекомендуется создать резервную копию конфигурации
- Для первоначальной настройки рекомендуется использовать проводное подключение
- Сторонние пакеты могут временно иметь проблемы совместимости или сборки после обновлений upstream-проектов
